# Node.js Express - Task Manager

Первый проект в рамках прохождения курса [Node.js and Express Course - Build 4 Projects](https://www.youtube.com/watch?v=qwE7F5vaZMk)[cite: 2].

## Описание проекта

Приложение представляет собой простой менеджер задач (Task Manager) с CRUD-операциями (Create, Read, Update, Delete), построенный с использованием Node.js, Express и MongoDB (Mongoose).
